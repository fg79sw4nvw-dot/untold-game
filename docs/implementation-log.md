# 実装ログ

## 現在の開発目標【確定】

**エルドを最初から最後まで通しでプレイできる状態にする。**

今後の実装・仕様決定は、この目標の達成に必要なものを優先する。ワールド全体の拡張や、エルド通しプレイに直接必要のない機能・地域・コンテンツは、原則として後回しにする。

### この目標で最低限つなぐゲームループ

- エルド内を移動できる
- NPCと会話できる
- 必要な情報をブックへ記録できる
- 依頼・イベントの進行状態を保持できる
- 時間・所持品・必要条件を参照してイベントを判定できる
- 条件達成時にカード化できる
- 取得カードがBOOKへ反映される
- エルド内の主要導線を最初から最後まで通してプレイできる

### 優先実装順

1. NPC・会話システム
2. 会話からの記録処理
3. 依頼・イベントフラグ
4. 汎用カード取得条件エンジン
5. No.01「忘れられた栞」の完全実装
6. No.55「書喰い鼠」の完全実装
7. 人物カード等、エルド内の確定済み取得フローの実装
8. エルド通しプレイに必要な施設・UI・セーブ・導線の接続
9. iPhone実機での通しプレイ確認と調整

## 0.3.2 — マップ遷移基盤とNo.01退出制御

### 今回実装した機能

- Wikiの確定済みマップ遷移仕様に基づき、汎用 `MapTransition` と `resolveTransition` を追加。
- 主人公の足元中央座標が入口・出口トリガー矩形へ入った時点で遷移候補を解決する構造を実装。
- 遷移ポイントは、ID・現在マップID・トリガー矩形・遷移先マップID・遷移先出現座標・条件判定を保持できる。
- 条件付き入口・出口を `gate` で制御し、許可・拒否と任意メッセージを返せる構造を実装。
- No.01「忘れられた栞」の `EldIntroFlow.attemptLibraryExit()` を遷移ゲートへ接続できることを統合テストで固定。
- ブック取得後かつNo.01未取得では図書館退出遷移を拒否し、No.01取得後は同じ退出遷移を許可することをテスト。
- 共通マップ遷移について、足元中央判定・別マップトリガー無視・条件付き拒否の自動テストを追加。

### 今回あえて実装していない内容

- 図書館内部マップの寸法、マップID、出口トリガー矩形、内部出現座標はWikiで未確定のため、実座標データは追加していない。
- エルド町側の図書館入口アンカー `(1504,960)` は確定済みだが、入口トリガー矩形サイズと図書館内部の出現座標が未確定のため、町→図書館の実遷移データはまだ作成していない。
- 栞の小さな光の具体座標も未確定のため、画面上の調査ポイント配置にはまだ接続していない。

## 0.3.1 — No.01進行・依頼状態基盤

### 今回実装した機能

- 汎用イベント状態を保持する `ProgressState` を追加。
- 指定カードNo.01〜99の取得済み状態を保持し、同じ指定カードを再取得できない `SpecifiedCardCollection` を追加。
- No.01「忘れられた栞」の確定フローを `EldIntroFlow` として実装。
  - ブック取得後に栞の小さな光を表示対象とする。
  - No.01未取得のまま図書館出口へ進むと退出を拒否し、「なにか見落としている気がする」と返す。
  - 光を調べるとNo.01を取得済みにする。
  - No.01取得後は図書館退出を許可する。
- 依頼状態の最小構造として `inactive / active / completed` を持つ `QuestTracker` を追加。
- No.55「書喰い鼠」で確定済みの司書導入会話3文と、重要情報3文を実装用データへ追加。
- No.55の3情報に内部 `clueId` を割り当て、会話記録基盤へ接続できる形にした。
- No.01フロー、および会話・記録・依頼状態の自動テストを追加。

### 今回あえて実装していない内容

- 図書館内部マップの寸法・出口座標・栞の光の具体座標はWikiで未確定のため、No.01の進行ロジックを実際のマップ座標へはまだ接続していない。
- No.01カードの取得演出とBOOK上の完成カード表示は、共通カードコンポーネントへの接続時に実装する。
- No.55の重要情報を話す具体的NPCは未確定のため、発言者は配置していない。
- No.55の特定調査ポイント座標は未確定のため、夜の図書館での餌設置処理にはまだ接続していない。
- 依頼失敗・破棄・再受注などは確定仕様がないため状態として追加していない。

## 0.3.0 — エルド進行基盤（着手）

### 今回実装した機能

- NPCごとの会話セッションを保持する `ConversationHistory` を追加。
- 同じNPCへ続けて話しかけた場合は同一セッションを継続し、新しい文だけを追記する構造を実装。
- 同一内容の文は会話履歴へ重複追加しない。
- 別NPCへ話しかけた時点で、新しい会話セッションへ切り替える。
- 会話文をブックの記録へ変換する `recordConversationSentence` を追加。
- 記録時だけ会話文に紐づく `clueId` が `RecordBook` へ入る構造とし、「聞いただけではclueIdを有効化しない」仕様へ接続。
- 同じNPCの同じ文は二重記録しない判定を追加。
- 指定カード取得条件を共通判定する `evaluateCardConditions` を追加。
- 条件要素として `clueId`、場所、時間帯、季節、天候、所持品、NPC状態、イベント状態、プレイヤー行動を扱える構造を追加。
- 指定カード1枚あたりの条件要素上限を確定仕様どおり8要素に設定。

### 今回あえて実装していない内容

- No.55の3情報を話す具体的なNPCはWikiで未確定のため配置・NPCデータ化していない。
- No.55の「特定ポイント」の具体座標は未確定のため取得地点判定へ接続していない。
- 会話UI・記録選択UIは、実際に配置するNPCと会話導線の確定情報が揃ってから接続する。

## 0.2.0 — 確定システム基盤

### 実装した機能

- 3本の主要橋について、確定した中心・角度・全長・通行可能幅96pxを使った徒歩通行上書き。
- 指定ポケットNo.01〜99の11ページ表示、矢印移動、左右スワイプ。
- BOOK内のフリーポケット、記録、レシピ確認用の最小開発UI。
- フリーポケット7分類、180枠、素材のみ最大99個のスタック処理。
- 満杯時に新規カードを自動取得せず、整理が必要であることを返す処理。
- 着用枠1・汎用枠2への装備、入れ替え、満杯時の取り外し禁止に対応する状態処理。
- 記録99件上限、複数clueId、削除時のclueId保持数、検索、並べ替えの状態処理。
- 初期時刻を外部から受け取る時間エンジン。現実1秒=ゲーム内2分、3日ごとの季節循環、時間帯区分、停止状態に対応。

### 実装を有効化していない部分

- 初期時刻・季節が未確定のため、時間エンジンはHUDへ接続していない。
- アイテム・装備の個別データが未確定のため、フリーポケットへサンプルカードを追加していない。
- 記録可能な実会話・文章データがないため、記録画面へサンプル記録を追加していない。
- マーク4種類の名称・色・アイコンが未確定のため、マークUIを実装していない。
- 山岳の急斜面・稜線の正確な衝突レイヤーが未収録のため、山岳横断制限は未実装。
