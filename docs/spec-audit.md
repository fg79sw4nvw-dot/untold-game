# 初期実装前仕様監査

- 監査対象: `fg79sw4nvw-dot/untold-wiki` / `main`
- 監査コミット: `584cbf53cca9f19b6e57a3ec3fb09f10dafd1f7b`
- 方針: 「確定」の明記または確定値だけを実装し、「一旦」「暫定」「案」「未定」は実装根拠にしない。

## 1. そのまま実装できる確定仕様

- ワールド座標系（16000×10000、左上原点）と確定基礎地形マスク。
- 主人公の表示幅40〜48px、衝突幅32px、1歩32px、通常移動110px/s。
- 徒歩で陸地を通行でき、水域を通行できない基本ルール。
- 数値座標が確定した8都市、具体アンカーが確定した4街道、位置と寸法が確定した3橋。
- 指定ポケット99枠、1ページ3×3、11ページ、未取得時は枠なしで番号のみ。
- 基本画面上部のHP・空腹・ジェニー・時間、左下の移動操作、右側のBOOK/CARD/MAPという配置基準。
- マップ遷移用のデータ構造と足元中央によるトリガー判定（具体トリガーは未収録）。

## 2. 一部のみ実装可能な仕様

- 地形・地域判定: ID、解像度、参照方法は確定しているが、4000×2500の各IDマスク本体が未収録。
- MAP: 探索済み範囲だけを表示する方針は確定しているが、探索半径・判定方式が未確定。
- HP・空腹・時間・季節: 最大値や区分は確定しているが、開始値・通常経過速度など初期状態に必要な値が不足。
- 町: 地理上の位置・役割は確定しているが、多くの内部マップ、衝突、入口、施設座標は未確定。
- BOOK・フリーポケット・記録・カード・スペル・装備・経済: UIとデータ構造の確定部分は多いが、開始所持状態や全データ、個別数値、具体配置が不足。

## 3. 現時点では実装しない仕様

- プレイヤーのゲーム開始座標と初期ステータス。
- マレスタ、スカルドの実装用数値座標。
- 未確定の残り6街道、M-02、M-03、スカルド接続ルート。
- NPC会話・依頼・施設・町内部マップのうち未確定の内容。
- 全99カードのうち未確定カード、および「一旦確定」カードを完成仕様として扱うこと。
- 探索済みMAP、遭遇、天候、サバイバル、ショップ、クラフト等のうち実行に未確定値が必要な処理。

## 初期版の境界

初期版はワールド座標・移動・確定街道/橋・確定座標の検証ハーネスと、未取得状態の指定ポケット第1ページを実装する。ゲーム開始地点を決めないため、起動時に「開発用起点」を明示して選択する。これはゲーム内の開始フローや開始地点を定義しない。

地形ID/地域IDマスクが未収録のため、地形・地域のゲーム判定は実装保留。徒歩の水域衝突確認に限り、確定基礎マスクを4000×2500へ描画して白黒を参照する。
