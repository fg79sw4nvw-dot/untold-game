## 接続済み

- ゲーム起動直後に開発用起点選択画面を出さず、冒頭独立映像から開始する。
- 冒頭の心の声7文を正本どおりの文面で自動表示する。
- 1文約4秒というWiki上の暫定基準をコード側でも暫定値として保持する。
- 冒頭終了後、通常ワールドの開発用画面ではなくエルド図書館導入フェーズへ遷移する。
- エルド図書館を現行正本の **10×16タイル / 640×1024px** へ更新した。
- 入口、本棚、補助本棚、司書カウンター、地下階段、閲覧机、椅子の確定タイル占有を実装用データへ反映した。
- 図書館開始イベントの整理位置 `(8,1) → (5,1) → (2,1) → (3,8)` と、BOOK発見位置 `(3,5)`、BOOK位置 `(3,4)` を実装用データへ反映した。
- 各本整理時とBOOK発見時の1秒停止を反映した。
- 司書 `「いつも手伝ってくれて、ありがとう。」`、主人公 `「好きでやってるだけなんで。」` をタップ送りの会話として接続した。
- 整理④からBOOK発見位置までは、確定仕様どおり中央本棚左側の `x=2` 側を回る経路で強制移動する。
- BOOK発見時の心の声 `（ん……？ この本は……？）` と、その終了0.5秒後のBOOK取得まで接続した。
- 強制移動の表示速度は、通常移動の共通基準 `110px/s` を使用している。
- BOOK取得後、閉じたBOOKを1秒表示する。
- 左側に番号のない空白ページ、右側に1ページ目タイトルページを表示し、タイトル文字は `UNTOLD` のみとする。
- タイトルページ表示後1秒待ってから `（……え？ 文字が……）` を通常会話HUD形式で表示する。
- その心の声を閉じた後、2–3ページの見開きへ切り替え、ゲームマスター最初のメッセージ全文を同時表示する。
- 全文表示後10秒間はタップによる閉じる操作を受け付けず、10秒経過後のタップでBOOKを閉じる。
- BOOKを閉じた後、通常の図書館表示へ戻し `（どういうことだ……？）` を表示する。
- 開始イベントの進行順を状態として保持する `OpeningSequenceController` を使用している。

## 現在の正式起動フロー

現在は

`冒頭独立映像 → 図書館開始イベント → BOOK発見・取得 → BOOK初回閲覧 → 初回閲覧後の主人公の反応`

まで自動接続する。

## 次の接続境界

次は、主人公の `（どういうことだ……？）` を閉じた後、**0.3秒後に司書の近くへ強制移動し、停止0.3秒後に司書への報告会話を開始する**部分。

報告会話本文、BOOKを渡した後の1秒、司書が主人公を見る1秒、`（自分にしか、見えてない……？）` 後の0.3秒、会話終了後の0.3秒は正本で確定済み。

ただし、現行正本には「司書の近く」で停止する具体タイル座標がまだ記載されていないため、その停止座標は勝手に補完していない。

## まだ未確定のため補完していない項目

- BOOK初回閲覧時に画面を暗くする具体的不透明度。
- BOOKの画面内サイズ・細かな見た目。
- BOOKを開くアニメーションの具体的な所要時間。
- タイトルページから2–3ページへめくる具体的な所要時間・細かな見せ方。
- 初回閲覧後、司書への報告を開始する際の主人公の具体的な停止タイル。
- 冒頭映像終了時の暗転・フェードの具体秒数。

初回BOOK閲覧では、開く／ページをめくる**状態境界**までは実装しているが、未確定のアニメーション秒数は固定していない。

## CIについて

2026-09-15、現行 `main` のCIで **テストとビルドがともに成功**した。

以前から赤になっていた2件は、本体の不具合ではなく現行データ・進行仕様へ追従していなかったテストだったため修正した。

- 記録テストは、実際に保存した会話文へ紐づく手掛かりを検証するよう修正。
- 図書館退出テストは、No.01取得直後は退出せずNo.55導入へ接続する現行進行を検証するよう修正。
